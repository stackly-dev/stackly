Bekerja di worktree dan branch yang sudah ada; branch, push, dan PR lain bukan urusan sub sesi. Bila brief menandai "Sesi dipakai ulang: ya", konteks lama sudah dibersihkan: jalankan `git merge main` dulu, lalu pakai brief dan `git log --oneline main..HEAD`. Nama branch bisa warisan item lain; biarkan.
- **Giliran pertama sesi baru:** bila brief menyebut `standby`, hanya baca brief, file ini, dan role, lalu akhiri giliran dengan `STATUS: standby` tanpa mengirim pesan; lead menaikkan effort lalu mengirim "mulai".

Run native dari artefak cache xtask tanpa unduhan boleh; bila artefak tidak ada, catat `BLOCKED` dengan `reason` dan `owner: user`. Selalu `export CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0`, juga saat commit (hook pre-commit menjalankan clippy). Bangun hanya paket yang dibutuhkan. Tiap worktree memakai `target/` sendiri: jangan berbagi `CARGO_TARGET_DIR` dan jangan menulis ke `target/` checkout utama (binary `xtask`, `stacklyd`, `provider_harness` saling menimpa). Sesi Swift boleh menunjuk `STACKLY_DAEMON_BIN` dan `STACKLY_SEED_BIN` ke binary checkout utama hanya untuk dibaca, selama protokolnya sama. Sebelum melapor `done`, hapus `target/` worktree sendiri (lead menjalankan gerbang di `main`).
- **Syncthing:** repo berada di folder Syncthing. Jangan pernah `git add` sebuah folder atau `git add -A`; tambahkan path satu per satu, dan pastikan `find . -name '*sync-conflict*' -not -path './target/*'` kosong sebelum commit.
- **Proses:** hentikan hanya proses yang kamu mulai sendiri. Test memakai `stackly_testkit::TestRoot` dan `allocate_port`, hanya kredensial fixture. Suite yang lebih lama dari 10 menit dijalankan terlepas (`nohup ... > <scratchpad>/<nama>.log 2>&1 &`), karena perintah latar dipotong di 10 menit.
