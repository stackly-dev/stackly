Bagian tetap dari setiap brief sub sesi koordinasi scope ini. Brief yang dikirim lead menunjuk file ini; isi brief menang bila berbeda.

Untuk lead: isi file ini sekali di langkah 1 SKILL.md, simpan sebagai `docs/scope/coordination/<nama-SCOPE>.brief-umum.md`, dan perbarui saat nilainya berubah (alamat lead, nomor bersama, disk). Butir bertanda `(bawa)` disalin dari file aturan umum scope terakhir (`ls -t docs/scope/coordination/*.brief-umum.md | head -1`) lalu dicocokkan dengan keadaan `main` sekarang. Hapus paragraf ini di file hasil.

- **Alur:** baca brief, file ini, lalu `.claude/skills/coordinate/roles/<peran>.md`, lalu panggil skill yang brief sebut lewat tool `Skill` (bila tool itu tidak ada, baca `~/.claude/skills/<skill>/SKILL.md` dan ikuti), baru bekerja. Bekerja di worktree dan branch yang sudah ada; branch, push, dan PR lain bukan urusan sub sesi. Bila brief menandai "Sesi dipakai ulang: ya", konteks lama sudah dibersihkan: jalankan `git merge main` dulu, lalu pakai brief dan `git log --oneline main..HEAD`.
